# Architecture Decision Records (ADR)

アーキテクチャ上の重要な設計判断を記録するドキュメント。
なぜその決定をしたかを将来の開発者（自分含む）が理解できるようにする。

## ステータス

| ステータス | 意味 |
|-----------|------|
| 提案 | レビュー待ち |
| 承認 | 採用済み |
| 廃止 | 別の決定に置き換え済み |
